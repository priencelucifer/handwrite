Handwrite handwriting for your 3D printer

Starting… How to use

Text

Marks: _underline these words_ · *second pen* (the printer pauses to swap pens).

Handwriting

Spacing is an average: every gap still varies a little like real handwriting, more with higher line wobble.

Page

Drag the paper on the build plate to where it will sit. Scroll to zoom.

Printing

Pen ran out, or the run stopped? Leave the paper where it is and save this page again from the line it stopped on. To write one word again, click it on the page.

plate edgewriting areapaper slideclick a word: write it again

Printer settings

Copy the pen offset that already works for you in BambuPlot, or measure it with the offset test. Pauses are timed: the printer carries on by itself when the time is up.
